Web & App UI

The built-in web interface is served directly by AquaChemD. The project documentation describes the phone/app presentation as the same interface adapted to screen size.

Dashboard

The UI presents sensor readings, limits, status and dosing controls. Tiles can display normal/high/out-of-range states, custom text, timers and dose status.

Dosing

Management and scheduler

The management console is reached from the menu. The scheduler uses standard cron syntax and is intended to control dosing cadence.

Configuration

The web UI includes configuration editing for the settings described in the project README, including sensors, GPIO, MQTT, dosing and interlock behavior.
