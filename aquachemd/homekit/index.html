HomeKit

Apple Home does not provide native pool-chemistry categories, so the project documents practical mappings through Home Assistant or the Homebridge AquaDaemon integration.

Documented mappings

AquaChemDSuggested HomeKit representationPurpose
pHHumidity or Light SensorProvides a numerical value on the Home tile
ORPLight Sensor / generic numerical presentationDisplays the reading despite the lack of a native ORP type
Acid doserSwitch / ValveSuitable for short dose bursts
Chlorine doserFaucet / ValveUses HomeKit's duration-style UI for longer doses
Flow conditionLeak / Contact style sensorProvides a visible safety indication
Pump conditionMotion style sensorCan be used as an automation condition

Homebridge AquaDaemon

If Homebridge is already being used, the AquaChemD README describes homebridge-aquadaemon as a direct MQTT integration that maps devices to native HomeKit types.
