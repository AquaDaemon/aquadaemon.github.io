Mounting Sensors

The biggest hurdle in getting started is probably how to mount the sensors and/or doser. There are a few options, below are some diagrams showing the main methods and connection points.

Inline

Sensors are mounted inline in the main flow, (usually 2" pipe)
Pros
  • Simplest installation — no bypass plumbing required
  • Sensors always in the primary flow stream
  • Fewest components and potential leak points on the bypass side
Cons
  • High flow velocity causes turbulence around sensor tips, affecting pH and ORP accuracy
  • A failed fitting or loose sensor is a significant leak on the main line.
  • Probes are exposed to the full force and debris of the pool's flow. can significantly shorten their lifespan.

Flow Cell

Sensors are mounted in a flow cell
Pros
  • Controlled low-velocity flow gives more stable sensor readings
  • Clear acrylic provides visual confirmation of water flow
  • Most major manufactures use a flow cell design
Cons
  • Cost: $80–$350 depending on model
  • Limited ports / expandability
  • Usually needs UV protection

Bypass

Sensors are mounted in a bypass tube
Pros
  • Controlled low-velocity flow gives more stable sensor readings
  • Cheap DIY install
Cons
  • Most complex and evasive install
  • Can be hard to make fit due to size
